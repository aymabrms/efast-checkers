Please implement one focused enhancement to the current SEC eFAST Checkers prototype:

COMPUTED CONFIDENCE + HITL V1

IMPORTANT:
- Inspect the current implementation first
- Keep this low-risk and low-credit
- Do NOT redesign the application
- Do NOT add OCR, spaCy/NLP, ML models, external APIs, or new dependencies
- Do NOT modify GIS, Historical View, Rankings, AFS completeness rules, demo seeding, or Test Upload Management

GOAL

Replace unexplained/fixed extracted-figure confidence with an explainable RULE-BASED confidence score using evidence already available in the current prototype.

The score must support Human-in-the-Loop routing.

This is NOT:
- an ML probability;
- an OCR confidence score;
- an automatic acceptance/reversion decision.

--------------------------------------------------
1. CREATE ONE SHARED CONFIDENCE CALCULATOR
--------------------------------------------------

Create one reusable helper/function for extracted-figure confidence.

Prefer an existing appropriate module or a small helper module.

Score range:
0–100

Use only evidence that CURRENTLY exists in the prototype.

Recommended weights:

A. Source Page Quality — 20 points

Use existing page-analysis quality/readability/text-length information.

Suggested:
- Readable / strong usable text = 20
- moderate / warning quality = 12
- low-text / poor readability = 5
- extraction failure / unusable evidence = 0

Do not invent OCR confidence because OCR is not implemented yet.

B. Financial Label Match — 25 points

Evaluate how reliably the raw financial label maps to the normalized field.

Suggested:
- exact supported label = 25
- configured alias / strong mapped variation = 20
- weaker normalized match = 12
- ambiguous / unsupported = 0

Use the existing label mapping/extraction rules.
Do not introduce ML similarity.

C. Fiscal Year Association — 20 points

Use the multi-year extraction evidence.

Suggested:
- selected fiscal year explicitly associated with the extracted value = 20
- year association is present but less direct = 12
- uncertain = 5
- no reliable year association = 0

Important:
2025, 2024, and 2023 rows must be scored independently.

D. Numeric Parse Quality — 20 points

Suggested:
- clean, safely parsed value = 20
- safely normalized after normal formatting cleanup = 15
- suspicious / ambiguous numeric formatting = 0

Existing Check Source behavior for malformed values such as:

6.837.912.90
A8849,399.68

must remain.

Do NOT automatically repair ambiguous values.

E. Unit Basis Certainty — 10 points

Suggested:
- explicit unit basis such as Pesos / Thousands = 10
- reliably inherited from page/report context = 7
- default/inferred = 3
- unknown = 0

Use only currently available evidence.

F. Source Evidence / Snippet — 5 points

Suggested:
- useful source snippet containing label/year/value context = 5
- partial context = 2
- no useful evidence = 0

Total = 100.

If current code cannot support one of these distinctions reliably,
implement the closest deterministic equivalent and document the exact behavior.
Do NOT fabricate signals merely to reach 100.

--------------------------------------------------
2. HARD SAFETY CAPS
--------------------------------------------------

Apply these safeguards after calculating the raw score:

- suspicious numeric formatting:
  maximum confidence = 49

- normalized value is NULL because parsing is unsafe:
  maximum confidence = 49

- source page has failed/very poor readability:
  maximum confidence = 69

Clearly document any other necessary cap.

Do not use confidence to manufacture missing values.

4. HITL ROUTING
--------------------------------------------------

Map confidence to an INITIAL review status:

HIGH:
"Ready for Quick Validation"

MEDIUM:
"Needs Review"

LOW:
"Check Source"

Important:

- Every result still remains reviewable by a human.
- High confidence must NOT automatically Accept a filing.
- Low confidence must NOT automatically Revert a filing.
- Final reviewer disposition remains unchanged.
- Existing suspicious-number Check Source rules take precedence.

If a reviewer has already edited/corrected a figure:
- do not silently overwrite the reviewed value;
- preserve reviewer edits.
